# 免费 API 下拉配置与使用

更新与官方资料核对日期：2026-11-03。新增页面配置，无需为常见服务手写地址或修改源码；不提供共享密钥或匿名绕过鉴权。

## 页面操作

1. Windows 双击 start_windows.bat，macOS 双击 start_mac.command，打开终端打印的地址。
2. 点击“知识配置”，找到“免费 API 与模型选择”。默认预选 OpenRouter 免费模型路由。
3. 下拉选择服务商和模型。点击“获取 API Key”前往官方平台，用自己的账户申请密钥。
4. 填入 Key，保持“模型生成（失败时明确提示）”，点击“保存并测试连接”。测试只发送一条“请仅回复 OK”的消息，不携带文档，会占用一次服务请求。
5. 连接成功后回到问答页面提问，点击答案来源检查“模型生成”标记。配置立即生效，无需重启。

首次预选不代表已经接入可用账户，必须填入自己的 Key。“保存配置”只保存本机设置，“保存并测试连接”才请求服务。自动模式可能直接返回 FAQ，演示 LLM 生成应选择“模型生成”。

## 预设服务

| 服务 | 默认模型 | 免费范围与注意 |
| --- | --- | --- |
| OpenRouter | openrouter/free | 自动路由到免费模型；需要 Key，有配额和限速，实际模型可能变化 |
| Groq | openai/gpt-oss-20b | 另可选择 GPT OSS 120B、Qwen 3.8 27B；使用 Free Plan，限制以账户控制台为准 |
| Google Gemini | gemini-3.8-flash | 使用 API 免费层；受账户、地区和配额影响，付费项目不能据此保证零费用 |

## 本机保存与配置优先级

配置及每个服务商各自的密钥保存在数据库旁的 .llm.json 文件，例如 data/rag.llm.json，不写入已被历史 Git 跟踪的 SQLite。Unix 权限为 0600，Windows 使用目录系统权限。文件为本机明文配置，应只保存在个人可访问目录。配置接口只返回是否存在 Key，不回传内容；保存后清空输入框，不存入浏览器 localStorage。

服务商切换时，密钥留空只保留该服务商以前保存的 Key，不误用其他平台密钥。改变自定义服务地址时不沿用旧地址的 Key，需要重新输入。“清除本机配置与密钥”删除配置文件；若启动环境中有 LLM_* 配置，则恢复使用环境变量。网页配置优先于旧环境变量；未保存网页配置时保留原有环境配置方式。

该设置只影响 LLM，不改变检索与 Embedding。默认字符检索也可调用模型 API；要使用语义 Embedding + FAISS，仍需安装 requirements-rag.txt 并按手册启用语义检索。

## 错误与评估

401 检查 Key；403 检查账户权限或地区；404 检查模型与地址；429 表示额度/频率限制。页面提供脱敏提示，不展示服务原始错误或密钥；达到限额后稍后重试或手动换服务。严格模式明确显示模型错误，不伪装成“知识库没有答案”。

正常问答会把问题和检索证据发送给所选服务，请使用获准发送的资料；数据使用规则以平台条款为准。连接测试只发送固定测试短句。

benchmark.py --with-llm 可读取网页保存的服务配置，在临时实验库中使用同一服务，结果不保存密钥。不加 --with-llm 的实验和原 8 题快速回归不调用保存的 API。打包脚本明确排除 *.llm.json 和临时密钥文件；新机器需重新配置自己的 Key。

本次使用受控响应验证保存、切换、请求构造和异常提示。尚无用户 API Key，未声称真实平台请求已经成功。
