# 实际失败案例分析（2026-11-03）

证据来源：reports/latest/benchmark.json。两种方案使用相同 45 个问题与原文回答模式；此处讨论实际检索/回答失败，不伪造 LLM 幻觉样本。本次没有真实 LLM 运行结果，所以不能把以下问题归因于模型生成幻觉。

## 总体结果

字符基线通过 33/45，语义 FAISS 方案通过 38/45。可回答题的答案关键词准确率从 69.44% 提升到 91.67%，证据 Hit@1 从 80.56% 提升到 91.67%；但无答案题的拒答准确率从 87.50% 降到 50.00%。这说明更高的语义召回伴随错误接受，不能只报告总体通过数。以上数字对应当前固定测试集，不代表独立测试集表现。

## 样本 1：到期时间与截止日期

extended_08：“任务能设置到期时间吗？”标准证据是“支持创建待办任务和设置截止日期”。字符基线检索到证据但因分数门槛拒答；语义方案返回正确证据并通过。原因是“到期时间／截止日期”的字符相似不足，语义模型改善同义表达匹配。复测应增加新的同义问题，并用独立开发集分析拒答门槛，不能为此题写特例。

## 样本 2：工作日关键词跨主题误命中

extended_21：“图书馆工作日几点开放？”字符基线回答了“电子在读证明在审核通过后 2 个工作日内提供下载”，正确答案是图书馆 08:00 至 22:00。由于校园指南包含多个主题，产品与版本隔离不能阻止同一知识库内部的跨主题串答；字符特征中过度依赖“工作日”。语义方案在此样本恢复正确答案。后续可增加主题过滤或重排器，并检验是否改善未见过的主题问法。

## 样本 3：同主体不同属性混淆

extended_28：“纸质在读证明去哪里领取？”字符基线返回“电子在读证明不收费，纸质在读证明每份收费 5 元”，正确证据是“携带学生证到行政楼 102 室领取；不能代领”。答案确实来自语料，却不回答领取地点；忠实度与相关性必须分开评判。语义方案在该样本通过。建议按办理地点、费用、时限和资格条件标注问题类型，检测属性匹配，避免仅靠产品名反复出现主导排序。

## 样本 4：借期与续借期限

extended_15：“普通图书可以借多久？”语义 Top-1 命中“可以续借 1 次，每次延长 15 天”，标准答案是普通借期 30 天。正确证据在 Top-3 中，但原文模式只返回 Top-1，造成答案错误。此处属于检索排序与上下文使用不足。LLM 接收 Top-3 有机会区分原始借期和续借时长，但必须通过真实生成实验确认，不能据此宣称已经修复。

## 样本 5：参考书外借的否定条件

extended_16：“参考工具书能带出图书馆吗？”语义 Top-1 返回续借操作，标准证据为“参考工具书仅限馆内阅览，不能外借”。正确证据同样在 Top-3；语义相似并不能保证主体与否定条件正确对应。可考虑交叉编码重排或事实槽位校验，并增加“能外借／不能外借”“参考书／普通图书”的对照问题。

## 样本 6：无依据功能与价格仍被接受

original_05 的语音转写问题，语义方案回答了“支持创建文字笔记和标签”；original_06 的价格问题，语义方案回答标签上限。两者都有相似领域证据，但缺少被问属性，系统未正确拒答。已有英文格式关键词检查也无法解决中文未知功能。需要单独评估证据充分性，采用独立开发集校准、无答案训练/标注或模型判定，并记录其误判，而非单纯降低检索阈值。

## 样本 7：考试周时间不能套用日常时间

unanswerable_04：“考试周图书馆几点关门？”资料明确说考试周另行公告。字符基线返回该声明，却将状态标为 answered，因此状态测试判错；这属于拒答状态识别不足，不是虚构时间。语义方案返回工作日和周末时间，容易让用户把日常安排当成考试周安排；这是条件遗漏导致的错误回答。后续应对“另行公告／未提供”做证据不足识别，并用多个表达评测，避免只匹配单句固定短语。

## 样本 8：邮寄问题不能用自取流程替代

unanswerable_05：“证明可以邮寄到家吗？”语义方案返回携带学生证到行政楼领取及不能代领，语料没有说明邮寄能力。此时应明确表示未知，不能从自取流程推断是否支持邮寄。更丰富上下文也可能让模型自行推断，所以需在真实 LLM 人评中单独标记无证据结论。

## 工程验证与后续实验

新增单元测试覆盖真实 FAISS 的产品/版本范围隔离、向量复用、模型标识变化、删除级联、API 响应排序与异常向量、严格模型模式异常及评分快照校验。模型调用使用受控测试响应验证协议与异常路径，不能称为真实 LLM 效果实验。实际语义实验采用下载的开源模型与真实 FAISS，不使用替身向量。

下一轮应分别保存基线、改进版本、开发集和保留测试集。改进优先顺序为：证据充分性与无答案判定、Top-3 证据组织及生成评测、条件与否定重排、独立开发集阈值校准。人工评阅与真实 LLM 数据尚未生成时保留空白，运行后再补具体的模型幻觉样本及复测证据。当前不承诺所有失败已经消除。
